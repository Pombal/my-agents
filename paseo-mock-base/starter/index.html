Every call allocates three times. Only one of them is needed:

  1. pad() builds the fill as its own String, then copies it.
  2. repeat() allocates again for each chunk of fill.
  3. The result needs one allocation. That one stays.
fn pad(s: &str, width: usize) -> String {
  // one buffer, sized up front
  let mut out = String::with_capacity(width.max(s.len()));
}
