# .agents

My agentic stuff.

Skills, `.omp/extensions/` and `.omp/themes/` go live when symlinked into the
matching folder under `~/.omp/agent/` (or a profile's); pick a theme with
`/theme`. `pi/extensions/` goes into `~/.pi/agent/extensions/`, and Herdr
plugins are enabled with `herdr plugin link <path>`.

Tampermonkey scripts have [install links](tampermonkey/README.md).
