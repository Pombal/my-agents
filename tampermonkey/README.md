# Tampermonkey

- [Discord Thread → Markdown](discord-thread-markdown.user.js) — copy a channel or thread as markdown, with permalinks and attachment URLs. Alt+Shift+C copies the visible view, or the current text selection. Alt+Shift+X, then click a message, copies from there down (max 100).
- [Gmail Attachment Harvester](gmail-attachment-harvester.user.js) — download every attachment in the current Gmail results, renamed `Sender - filename`, into a folder you pick. Chromium only (Chrome, Edge, Brave). Firefox cannot.
- [X Tweet Shot](x-tweet-shot.user.js) — click a tweet, get one PNG of it and its own replies, permalinks stamped in the footer, on the clipboard. Alt+Shift+S, or the corner triangle.
